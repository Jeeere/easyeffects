# Tape Echo

Tape Echo repeats a sound after a delay and feeds part of the delayed signal back to create further echoes. Easy Effects uses the Vintage Delay LV2 plugin developed by Calf Studio Gear. The Calf plugin must be installed to use this effect.

**Medium**

Selects the character of the delay. Plain does not apply the tape filter; Tape and Old Tape apply different degrees of filtering to the echoes.

**Delay Time**

Time between the original signal and the first echo, in milliseconds. The same delay is applied to the left and right channels.

**Feedback**

Amount of the delayed signal fed back into the delay. Higher values produce more repeats.

**Dry**

Amount of unprocessed signal mixed into the output.

**Wet**

Amount of delayed signal mixed into the output. Dry and Wet are independent levels.
